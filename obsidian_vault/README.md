# RM Intelligence Obsidian Vault

Companion knowledge layer for the local Streamlit workbench. Keep qualitative
RM research, meeting preparation and theme notes here. Structured portfolio
data in `data/` remains the source of truth.

Suggested folders: `Clients/`, `Events/`, `Themes/`, and `Workbench/`.

Do not copy raw client data into external plugins or send vault contents to
third-party APIs without an approved governance review.
